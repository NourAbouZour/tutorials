What this guide will help you do

When you ask Claude to "make me a website", it usually works, but it often looks plain: no movement, basic buttons, flat charts. Professional sites feel alive because they're built with good animation libraries and ready-made components.

These five websites give Claude those building blocks. You don't need to learn to code. You need to know which one to use for what, and how to tell Claude to use it. That's what this guide covers.

Before you start: two ways to build with Claude

Way A: a normal Claude chat

At claude.ai or in the app. Best for one-page things like a landing page or a single animated section. Claude shows you a live preview. Works great with Anime.js and Motion.

Way B: Claude Code

The Code tab in the Claude desktop app (paid plans). Claude builds a real project in a folder on your computer. You need this for Kokonut UI and Bklit UI, which are made for React projects.

Don't worry about the tech words

You'll see words like React, Tailwind and shadcn/ui on these websites. They're just the tools the components are built with. Claude knows all of them. When you use Way B, Claude installs and sets up everything for you. There's a mini glossary at the end if you're curious.

The one trick that makes it work

Claude knows a lot, but these libraries update often. So always give Claude the link to the exact page or component you want, and tell it to read that first. This one habit fixes most problems.

1

Anime.js

animejs.com · free and open source

Anime.js is a very powerful animation library. If you can imagine an animation, you can probably make it with Anime.js: text that appears letter by letter, shapes that draw themselves, grids of dots that ripple, numbers that count up, or elements that move as you scroll.

How to use it

  1. Open animejs.com and browse the examples and documentation. Find an effect you like.
  2. Copy the link to that example or docs page.
  3. Ask Claude to use it in your page (Way A or B both work).
COPY THIS PROMPTAnimated hero section
Build a hero section for my website about ___ using Anime.js.
- The headline "YOUR HEADLINE" appears letter by letter
- A soft background of dots gently ripples in a wave
- The button bounces in slightly after the text
Keep the animations smooth and under 1.5 seconds in total, and make it look good on phones too.

Before you start, read this page and follow its latest instructions: ANIME.JS DOCS OR EXAMPLE LINK
Ideas to try

"Draw my logo outline like it's being sketched", "count my stats up from 0 when they scroll into view", "make the cards fly in one after another (staggered)".

2

Motion

motion.dev · formerly Framer Motion · free core library

Motion is the go-to library for smooth transitions: pages that slide in, menus that open softly, cards that lift when you hover, and lists that rearrange themselves without jumping. It's what makes a website feel premium instead of stiff. It works with plain JavaScript and with React.

Anime.js or Motion?

Use Motion for the everyday movement of your interface (opening, closing, hovering, switching pages). Use Anime.js for show-off moments (a special hero animation or a drawing effect). Many sites use both.

COPY THIS PROMPTSmooth transitions
Use Motion (motion.dev) to make my website feel smooth and premium:
- Sections fade and slide up gently as they scroll into view
- Cards lift slightly with a soft shadow when I hover them
- The mobile menu slides open and closed smoothly
- Switching between pages or tabs cross-fades instead of jumping
Use spring animations that feel natural, keep everything quick (under 0.4 seconds), and turn the animations off for people who've set "reduce motion" on their device.

Before you start, read: MOTION DOCS LINK
Free vs paid

The Motion library is free. The site also sells "Motion+" with extra examples and tools, but you don't need it for anything in this guide.

3

Kokonut UI

kokonutui.com · 100+ free animated components

Kokonut UI is a big collection of ready-made animated components: buttons with particle effects, animated AI chat inputs, smooth drawers, scrolling text, cards and more. Each one is already designed and animated, so you just copy it in. It's made for React projects (it uses Tailwind, shadcn/ui and Motion), so use Way B (Claude Code).

How to use it

  1. Browse kokonutui.com and open a component you like.
  2. Copy either the component's page link, or its install command (it looks like npx shadcn@latest add …), or the code itself.
  3. Paste it to Claude Code with the prompt below. Claude installs it and fits it into your page.
COPY THIS PROMPTAdd a Kokonut component
Add this Kokonut UI component to my website: COMPONENT LINK, INSTALL COMMAND OR CODE

- If my project isn't set up for it yet (React, Tailwind, shadcn/ui), set that up first and explain each step in one sentence
- Use it for my sign-up button / the hero section / the pricing cards
- Change the colours and text to match my brand: YOUR COLOURS AND TEXT
- Make sure it still looks good on phones
Using ChatGPT or a normal Claude chat?

You can paste a component's code into a chat and ask: "Explain what this does and adapt it for my page." But to actually run React components, Claude Code is the easiest path.

Check the licence for business use

Kokonut UI is open source, but the licence can differ from component to component. If you're building for a client or a business, check the licence shown for each component you use.

4

Bklit UI

ui.bklit.com · free animated chart components

Bklit UI is the one to use for dashboards. It's a free, open-source collection of chart components where everything is animated: line charts that draw in, bars that grow, rings that fill up, live-updating charts, heatmaps and more. Like Kokonut UI, it's made for React projects, so use Way B (Claude Code).

COPY THIS PROMPTAnimated dashboard
Build me a dashboard for my online shop / my Instagram stats / my business using Bklit UI charts.

Read the docs first and follow its latest install instructions: https://ui.bklit.com

Show:
- 4 stat cards at the top (e.g. revenue, orders, new followers, conversion rate) with numbers that count up
- A line chart of sales over the last 30 days
- A bar chart of sales by product
- A ring chart of where my customers come from

Use realistic sample data for now, in one separate file, so I can swap in my real numbers later. Make it work on phones.
Use your real data

Export your numbers from Instagram Insights, Shopify, Google Sheets or anywhere else as a CSV file, put it in your project folder, and tell Claude: "Replace the sample data with the numbers in sales.csv."

5

Manus

manus.im · AI agent · free daily credits, paid plans available

Manus is different from the other four. It isn't a library, it's an AI agent. You describe your idea, and it works on its own to research, design and build a first version: a design, a dashboard or a full website. Your job is the review and the finishing touches.

How to use it

  1. Sign up at manus.im.
  2. Describe what you want in detail (use the prompt below), then let it work. It can take several minutes.
  3. Review the result: open it on your phone, click everything, read every word.
  4. Ask Manus for changes, or download the files and finish it in Claude Code with the other four tools.
COPY THIS PROMPTFor Manus
Build a landing page / dashboard / full website for MY BUSINESS OR IDEA.

Who it's for: YOUR CUSTOMERS
What visitors should do: e.g. book a call, buy, sign up
Pages or sections: e.g. hero, features, testimonials, pricing, FAQ, contact
Style: e.g. clean and bright, purple and blue, modern
Websites I like the style of: LINKS

Make it work well on phones. Use placeholder text only where you must, and list everything I need to replace.
Credits can run out mid-build

Manus runs on credits. The free plan gives a small daily amount, and a full website can use most of it. If a big task stops halfway, that's usually why. Paid plans start at around $20 a month (at the time of writing). Check the pricing page for the latest.

Always review

An AI agent can get details wrong: fake phone numbers, broken links, made-up testimonials. Never publish its work without checking every page yourself.

Good-taste rules for animation

  • Less is more. One impressive moment beats twenty things moving at once.
  • Keep it fast. Most interface animations should take 0.2–0.5 seconds. Slow animations feel laggy.
  • Animation should help. Use it to show what changed or where to look, not just for decoration.
  • Respect "reduce motion". Some people get dizzy from movement. Ask Claude to turn animations off for them.
  • Test on a real phone. What's smooth on a laptop can be jumpy on a cheap phone.

Fixes

Mini glossary

LibraryA ready-made toolbox of code that does one job well, like animation.
ComponentA ready-made piece of a website, like a button, a card or a chart.
ReactA very popular way to build websites out of components.
Tailwind / shadcn/uiPopular tools for styling websites and adding components. Claude sets them up for you.
TransitionThe movement between two states, like a menu opening or a page changing.
AI agentAn AI that works on a task by itself, step by step, instead of only answering one message.
CreditsThe units some AI tools (like Manus) use to measure how much work you've used.
