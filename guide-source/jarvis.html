What OpenJarvis is

Open source

Free, with the Apache 2.0 license. The code is public on GitHub, so you can read it, change it and keep it forever.

Local first

It runs AI models on your own computer by default (through a free tool called Ollama), and only uses the cloud when you choose to.

Set it up

1

Let Claude Code set it up

15–30 minutes · Claude does the work
  1. Create a folder on your computer called Jarvis.
  2. Open the Claude desktop app, click the Code tab, start a Local session, and choose that folder.
  3. Paste the link and the prompt below. In the reel I just say "set this up on my machine", and that works. The extra lines keep you in control.
COPY THIS PROMPTSet up Jarvis
https://github.com/open-jarvis/openjarvis
Set this up on my machine.

I'm a beginner, so:
1. Read the README first and tell me in 5 lines what OpenJarvis
   does and what it will install on my computer.
2. Use the official installer for my system (Mac, Windows or
   Linux) from the README. Explain each step in one simple sentence.
3. When it's done, run "jarvis doctor" and tell me if anything
   is missing.
4. When something needs an API key, tell me exactly where to put
   it. I'll paste keys there myself, never in this chat.
5. At the end, show me how to start Jarvis, update it, and
   uninstall it if I ever want to.

The installer sets up everything OpenJarvis needs (Python, uv, Ollama) and downloads a first AI model. It takes a few minutes on good internet. Then type jarvis to chat with it.

Let it ask, then say yes

Claude asks before it installs things. Read what it says, and if something isn't clear, ask "What is that and why does Jarvis need it?" before you approve.

2

Give Jarvis a voice with ElevenLabs

10 minutes
  1. Go to elevenlabs.io and create a free account.
  2. Open the Voices section and listen to a few. Pick one you like: calm and British if you want the classic Jarvis feel. Make sure it's available on your plan.
  3. Copy the voice's Voice ID from its options.
  4. In your account settings, find API Keys and create a new key. Name it Jarvis.
  5. Tell Claude Code:
COPY THIS PROMPTSet up the voice
Set up ElevenLabs as Jarvis's voice for the morning digest.
My voice ID is PASTE THE VOICE ID.
Set tts_backend to "elevenlabs" and my voice ID in the [digest]
section of ~/.openjarvis/config.toml.
Then tell me where to put my ELEVENLABS_API_KEY so it's saved
safely. I'll paste the key there myself.
Your API key is like a password

Anyone with your key can use your ElevenLabs credits. Never paste it in a chat, a screenshot or a public file. If you leak it, delete it in ElevenLabs and create a new one. Also know that with a cloud voice, the text of your briefing is sent to ElevenLabs to be spoken. If you want everything to stay on your computer, OpenJarvis also has a free local voice called Kokoro.

3

Connect your calendar, inbox and more

10–15 minutes

This is what turns a talking toy into a real assistant. OpenJarvis connects to Google with one sign-in that covers Gmail, Google Calendar, Tasks, Contacts and Drive. Ask Claude to walk you through it:

COPY THIS PROMPTConnect my tools
Connect Jarvis to my Google account (Gmail and Calendar) with
"jarvis connect gdrive". Walk me through creating the Google
client ID and secret step by step. I'll do the Google screens and
paste the values myself. Then show me "jarvis connect --list".

After that, tell me what else OpenJarvis can connect to (weather,
news, GitHub, health apps...) and help me add WEATHER / NEWS / ...
What about my revenue?

At the time of writing, OpenJarvis has no built-in Stripe or Shopify connector. Two easy options: keep your revenue in a Google Sheet on your Drive (Jarvis can already read Drive), or, because it's open source, ask Claude Code: "Add my daily revenue from Stripe / Shopify to the morning digest, with a read-only key."

Use it every day

4

Your first morning briefing

5 minutes

OpenJarvis has a ready-made morning digest. Ask Claude Code to set it up:

COPY THIS PROMPTMorning briefing
Set up the OpenJarvis morning digest for my computer, using the
right preset (morning-digest-mac, morning-digest-linux or
morning-digest-minimal). Then:
1. Run "jarvis digest --fresh" so I can hear my first briefing.
2. Schedule it every weekday at 8:00 in my time zone.
3. Make the style like Jarvis: calm, short, a little dry humour,
   and call me "sir / boss / your name".
4. Tell me if my computer needs to stay on for the schedule to work.

That's how you get lines like: "The call at half one collides with the accelerator sync, and you have not yet replied to it."

Not comfortable typing commands? Just ask Claude Code in your Jarvis folder: "Run my digest", and it types them for you.

Make it yours

Optional

It's open source, so you can change anything. Open your Jarvis folder in Claude Code and ask, for example:

  • "Add the weather and my Google Tasks to the morning briefing."
  • "Use Claude as Jarvis's brain instead of the local model." (This needs an Anthropic API key, which is paid per use. The local model is free.)
  • "Make Jarvis start automatically when I turn on my computer."
  • "Always ask me before sending an email or changing my calendar."
Stay safe with open-source tools
  • Install from the official source only: github.com/open-jarvis/openjarvis and the installer linked in its README. Not from copies or random links.
  • You own it, so you protect it. Your keys and data stay on your computer. Keep your computer locked and updated.
  • Read-only first. Only give Jarvis permission to send emails or change your calendar when you trust it, and keep "ask me first" on.
  • Watch your usage. The local model is free. Cloud voices and cloud AI models use credits. Check your ElevenLabs usage in the first week.

Fixes

"jarvis: command not found"Close and reopen your terminal (or the Claude app), then try again. Ask Claude to check the install if it still fails.
It's slowThe local model runs on your computer's power. Ask Claude to switch to a smaller model, or to a cloud model.
No voice in the briefingCheck your ElevenLabs key, voice ID and remaining credits, then run jarvis digest --fresh again.
It can't see my calendar or emailRun jarvis connect --list. If Google isn't connected, run jarvis connect gdrive again.
The briefing didn't play at 8:00Your computer may have been asleep. Ask Claude how to keep the schedule running.
