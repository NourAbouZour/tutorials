Set it up

1

Get the Jarvis project link

1 minute

The project lives on GitHub, a website where developers share code. Open the link and copy it from your browser's address bar:

THE PROJECTGitHub link
GITHUB LINK FROM THE REEL / MY DM

On the project page, scroll down to the README. It explains what this Jarvis can do and what it needs. You don't have to understand all of it. Claude will read it for you.

2

Let Claude Code set it up

15–30 minutes · Claude does the work
  1. Create a folder on your computer called Jarvis.
  2. Open the Claude desktop app, click the Code tab, start a Local session, and choose that folder.
  3. Paste the link and the prompt below. In the reel I just say "set this up on my machine", and that works. The extra lines keep you in control.

Let it ask, then say yes

Claude asks before it installs things. Read what it says, and if something isn't clear, ask "What is that and why does Jarvis need it?" before you approve.

3

Give Jarvis a voice with ElevenLabs

10 minutes
  1. Go to elevenlabs.io and create a free account.
  2. Open the Voices section (the Voice Library) and listen to a few. Pick one you like: calm and British if you want the classic Jarvis feel.
  3. Open the voice's options and copy its Voice ID.
  4. Open your account settings, find API Keys, and create a new key. Name it Jarvis.
  5. Paste the key and the Voice ID into the settings file Claude showed you (often called .env). Save the file.
  6. Tell Claude: "I added my ElevenLabs key and voice ID. Set up the voice and play a test sentence."
Your API key is like a password

Anyone with your key can use your ElevenLabs credits. Never paste it in a chat, a screenshot or a public file. If you leak it, delete it in ElevenLabs and create a new one.

4

Connect your calendar, inbox and revenue

10–15 minutes

This is what turns a talking toy into a real assistant. Every Jarvis project supports different tools, so ask Claude first:

COPY THIS PROMPTConnect my tools
Which tools can this Jarvis connect to? I want:
- my calendar: Google Calendar / Outlook / Apple Calendar
- my inbox: Gmail / Outlook
- my revenue: Stripe / Shopify / a Google Sheet

Connect them one at a time. Use read-only access wherever you can.
Walk me through every sign-in screen, and tell me exactly what
Jarvis will be able to see and do with each one.
  • Calendar and email: you'll usually sign in with Google or Microsoft in your browser and click Allow. Read what access it asks for.
  • Revenue: for Stripe or Shopify, Claude may ask you to create a restricted, read-only key in their dashboard. Read-only means Jarvis can see your numbers but can't move money.

Your first morning briefing

2 minutes

Start Jarvis the way Claude showed you, and ask for your briefing. Then ask Claude to make it automatic:

COPY THIS PROMPTMorning briefing
Set up a spoken morning briefing that runs every weekday at 8:00.
It should tell me, in under a minute:
1. How many items I have today, and anything that clashes.
2. Emails I haven't replied to that matter.
3. Yesterday's revenue compared with my usual day.
4. The one thing I should do first.
Speak like Jarvis: calm, short, a little dry humour, and call me "sir / boss / your name".

This is how you get lines like: "The call at half one collides with the accelerator sync, and you have not yet replied to it."

7

Make it yours

Optional

It's open source, so you can change anything. Open your Jarvis folder in Claude Code and ask, for example:

  • "Add a wake word, so it only listens when I say 'Jarvis'."
  • "Add the weather and my to-do list to the morning briefing."
  • "Make it start automatically when I turn on my computer."
  • "Always ask me before sending an email or changing my calendar."
Stay safe with open-source tools
  • Only install projects you trust. Look at the GitHub page: is it active, does it have many stars, are there recent updates? Ask Claude to check the code before installing (Step 2 does this).
  • You own it, so you protect it. Your keys and data stay on your computer. Keep your computer locked and updated.
  • Read-only first. Give Jarvis permission to send emails or change your calendar only when you trust it, and keep "ask me first" on.
  • Watch your usage. Voice and AI use small amounts of credits. Check your ElevenLabs and Claude usage in the first week.

Mini glossary

Open sourceSoftware whose code is public. You can download it, change it and run it yourself.
GitHubThe website where developers share code projects.
READMEThe page that explains what a project does and how to install it.
API keyA secret key that lets an app use a service, like ElevenLabs. Treat it like a password.
Voice IDThe code for the exact voice you chose in ElevenLabs.
.env fileA settings file where apps keep secret keys on your computer.
Read-onlyAccess that can look at data but can't change it.
