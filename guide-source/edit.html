What this guide will help you do

Editing a reel by hand means cutting every pause, typing every caption, finding music and animating text. That takes hours. With Claude Code, you set up an editing "studio" on your computer once. After that you drop in a video, send one prompt, and Claude edits it in your style.

Don't like something? You tell it, just like you'd tell a real editor: "captions smaller", "cut the part at 0:12", "music quieter".

Your editing team

Claude Code is a version of Claude that can work directly with files and programs on your computer. It doesn't edit video by itself. Instead, it operates four free tools, like an editor using their software:

FFmpeg

The world's most used video tool. It cuts, joins, resizes, adds audio and exports. Claude uses it for all the basic editing.

Whisper

Free speech-to-text from OpenAI that runs on your computer. It writes down every word with its exact timing, which is how Claude finds pauses and syncs captions.

Hyperframes

Turns web-style designs into video. Claude uses it to build animated captions, titles, lists and number pop-ups.

yt-dlp

Downloads a video from a link. You'll use it to give Claude reels whose style you like, so it can study them.

1

Install Claude Code and make your folders

About 10 minutes

1a. Get the app

  1. Download the Claude desktop app from claude.ai/download and install it.
  2. Open it and sign in with your Claude account.
  3. Click the Code tab at the top. That's Claude Code.

1b. Make your editing folder

In your Documents, create a folder called AI Video Editor with these folders inside it:

FolderWhat goes in it
raw-footageThe videos you filmed and want edited
referencesReels whose style you want to copy (Claude fills this for you)
exportsYour finished, ready-to-post reels
music (optional)Songs you're allowed to use

1c. Open it in Claude Code

  1. In the Code tab, start a new session.
  2. When it asks where to work, choose Local (your own computer).
  3. Select your AI Video Editor folder.
Always open this folder

Every time you want to edit, start your session in the AI Video Editor folder. That's where Claude finds your footage, your style sheet and your tools.

2

Install the editing tools

15–30 minutes, mostly waiting

You don't install anything by hand. Claude does it. Paste this:

COPY THIS PROMPTInstall tools
I'm a complete beginner and I'm on Windows / Mac. Set up this folder as my video editing studio.

Install these tools: Hyperframes, FFmpeg, Whisper and yt-dlp.
- First check which ones are already installed
- Install anything they need to work (for example Python or Node.js)
- Before each step, explain in one simple sentence what you're doing
- At the end, test each tool and show me a table: tool / installed? / version

If you need me to click or approve something, tell me exactly what to do.

Claude will ask permission to run commands. Read the one-line explanation and click Allow. Some downloads are large, so this can take a while.

If something needs a restart

Sometimes a freshly installed tool isn't found until you start a new session. If Claude says a tool is "not found" right after installing it, close the session, open a new one in the same folder, and ask Claude to run the test again.

3

Create your style sheet

About 10 minutes · you do this once

A style sheet is a written description of how your reels should look and feel: pacing, captions, zooms, music, graphics. Claude writes it by studying 3–5 reels you love. After this, every edit follows it automatically.

COPY THIS PROMPTStyle sheet
Here are reels whose editing style I love:
LINK 1
LINK 2
LINK 3

1. Download them into the references folder with yt-dlp.
2. For each one, grab a frame every second with FFmpeg and look at them, and use Whisper to get the transcript with timings.
3. Study and measure:
   - The hook: what happens in the first 3 seconds
   - Pacing: average seconds between cuts, how pauses are removed
   - Captions: font, size, colour, position, words per line, highlighted words, animation
   - Zooms and punch-ins: how often and how strong
   - Motion graphics and text pop-ups: when and what style
   - Music: energy, and how loud compared to the voice
   - Sound effects, transitions, colour look, how the video ends
4. Write everything into style-sheet.md in this folder, as a style guide a professional editor could follow. Use exact numbers wherever possible.

Then show me a short summary of my style.
Reference only

Downloaded reels are only for Claude to study. Don't repost or reuse other creators' videos. If a download fails (Instagram sometimes blocks it), save the reel some other way, put the file in references yourself, and tell Claude "the reels are already in the references folder".

Open style-sheet.md and read it. Want to change something? Just say: "Update the style sheet: captions should always be yellow."

4

Edit your first reel

About 10–20 minutes, depending on your computer
  1. Put your video in raw-footage. Give it a simple name like reel-01.mp4.
  2. Send this prompt:
COPY THIS PROMPTEdit a reel
Edit raw-footage/reel-01.mp4 into an Instagram Reel that follows style-sheet.md.

1. Transcribe it with Whisper (with word timings).
2. Cut pauses longer than 0.3 seconds, "umm"s, false starts and repeated takes (keep the best take).
3. Make the first 3 seconds a strong hook, following my style sheet.
4. Add captions in my style, synced word by word.
5. Add punch-in zooms on key moments.
6. Use Hyperframes for motion graphics on key points, numbers and lists.
7. Add music from the music folder under my voice, quieter whenever I speak. Skip this if the folder is empty.
8. Export as a vertical 1080x1920 MP4 at 30fps to exports/reel-01-v1.mp4.

Before you render anything, show me your plan (what you'll cut, and where captions, zooms and graphics go) and wait for my OK.

Check the plan, reply OK (or change something), and Claude will build the video. When it's done, open the file in exports and watch it.

5

Give feedback like a director

As many rounds as you want

This is where it feels like working with a real editor. Say what you don't like in plain words. The clearer you are, the better the result.

Example feedbackWhy it works
"Cut from 0:12 to 0:15, I stumble there."Exact timestamps mean no guessing.
"Captions are too big. Make them 20% smaller and move them a bit higher."Specific and measurable.
"The music is too loud, I can't hear myself."Describes the problem you noticed.
"The first 5 seconds feel slow. Make the cuts faster."Says where and what feeling you want.
"Add a pop-up with the number '3 steps' when I say it."Says what to add and when.
"Save this as v2 and keep v1."Lets you compare versions.
Make it learn

When you correct the same thing twice, say: "Add this to my style sheet so you always do it." Your edits get better with every reel.

6

Export and post

2 minutes
  • Your final reel is in exports. Send it to your phone (AirDrop, Google Drive, WhatsApp to yourself, or a USB cable).
  • Upload it in Instagram as a Reel. If you didn't add music, you can pick a sound from Instagram's library at this point.
  • Want a thumbnail? Ask: "Make a cover image from the best frame, with the title 'YOUR TITLE' in my caption style."

Fixes

ProblemWhat to do
"Command not found" after installingStart a new session in the same folder (or restart the app), then ask Claude to test the tools again.
Whisper is very slowAsk: "Use a smaller Whisper model, like 'small' or 'base'." It's a little less accurate but much faster.
Captions are out of syncAsk: "Re-sync the captions using Whisper's word timings, and check them against the audio."
Words in the captions are wrongTell Claude the correct spelling once: "My name is spelled Nour, fix it everywhere and remember it in the style sheet."
The video is sideways or has black barsAsk: "Make it a vertical 9:16 1080x1920 video that fills the screen, no black bars."
A reference reel won't downloadInstagram sometimes blocks downloads. Put the video file in references yourself.
Rendering takes foreverAsk for a quick low-quality preview first, and only export full quality when you're happy.
