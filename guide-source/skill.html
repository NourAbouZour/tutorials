What this guide will help you do

Out of the box, Claude can't watch a YouTube video, scroll X, or read a LinkedIn company page. The official way to connect to those sites is through their APIs, which often cost money and take ages to set up.

Agent Reach fixes that for free. It's an open-source tool on GitHub that gives AI agents like Claude Code the ability to read and search the big platforms. Install it once, and you can say things like "analyse this YouTube video" or "see what's trending on Instagram in my niche".

What Agent Reach is

Agent Reach is a free tool (MIT licence) made by the developer Panniantong, and it's one of the most popular tools of its kind on GitHub. It isn't a new AI. It's like giving Claude a set of eyes for the internet: it installs and connects the tools Claude needs to read each platform, then tells Claude how to use them.

YouTube

Read a video's transcript and details, so Claude can summarise or analyse it.

X (Twitter)

Search posts and read threads to see what people are saying.

Reddit

Read discussions to find real questions, complaints and ideas.

LinkedIn and Instagram

Research companies, people and trends. These two need you to log in.

The list of supported platforms grows and changes. The project's README on GitHub always has the latest list.

1

Open Claude Code

1 minute
  1. Open the Claude desktop app and click the Code tab.
  2. Start a new session, choose Local, and pick a folder, for example a new folder called Research in Documents.
2

Install Agent Reach

About 5 minutes

One message, and Claude does the whole install:

COPY THIS PROMPTInstall
Install Agent Reach from https://github.com/Panniantong/Agent-Reach

Read the README first and follow its install instructions exactly. I'm a beginner on Windows / Mac, so explain each step in one simple sentence before you do it.
When you're done, run its check command and show me a table of every platform: working / needs login / not working.

Claude will ask for permission to run commands. Read the explanation and click Allow.

3

Check what's working

1 minute

Do a quick real test:

COPY THIS PROMPTTest
Use Agent Reach to read this YouTube video and give me a 5-bullet summary: ANY YOUTUBE LINK

If you get a summary of the actual video, it works.

4

Logging in to LinkedIn and Instagram

Only if you need them

LinkedIn and Instagram hide most things from people who aren't logged in, so for those two Agent Reach needs to use your login. Ask Claude to walk you through it:

COPY THIS PROMPTLogin setup
Walk me through connecting my LinkedIn / Instagram login to Agent Reach, the way its README recommends. Keep my login details stored only on this computer, and never print them in the chat.
Your login is like your password

Never paste your password into a chat, and never share login files or "cookies" with anyone. They give full access to your account. Keep them on your own computer only.

The rules that keep your account safe
  • Don't scrape in bulk. Reading a few pages for research is fine. Pulling thousands of profiles at once looks like a bot, and platforms ban accounts for it.
  • Never use the data for spam. No mass messages, no bulk lists of people's details.
  • Respect privacy. Research companies and public trends, not private individuals.
  • Read each platform's rules. Free access works by reading the sites the way a browser does, not through their official paid APIs. Use it lightly, and the risk to your account is on you.

Fixes

ProblemWhat to do

Got blocked or asked to verify you're humanStop for a day and use it more lightly. You're making too many requests.
