Why page 2 is the secret

Almost nobody clicks on page 2 of Google. But a page sitting at position 11–20 is close: Google already thinks it's relevant. It usually needs only a better title, a clearer answer, or a missing section to jump to page 1.

Page 1 (1–10)Where almost all the clicks go. Protect these pages.
→
Page 2 (11–20)Your quick wins. This is where CLIMB focuses.
→
Page 3+ (21+)Needs bigger work. Leave these for later.

1

Set up Google Search Console

About 10 minutes, then a few days of waiting
  1. Go to search.google.com/search-console and sign in with Google.
  2. Click Add property and enter your website address.
  3. Follow Google's steps to verify you own it. Most website builders have a simple option for this. If you're stuck, ask Claude: "How do I verify my WordPress / Shopify / Wix site in Google Search Console?"
  4. Wait a few days. If your site is brand new to Search Console, it needs time to collect data.
2

Export your data

2 minutes
  1. In Search Console, open Performance → Search results.
  2. Set the date range to the last 28 days, and click the Average position box so positions show.
  3. Click Export (top right) and download it as a CSV file. The download includes your top queries and pages.
Fresh data, better results

Export a new file each time you run CLIMB, so Claude works with your latest positions.

3

Set up your SEO folder

3 minutes
  1. Create a folder called SEO in Documents, with a folder inside it called data.
  2. Put your Search Console export in data. Unzip it if it downloaded as a ZIP.
  3. In the Claude desktop app, open the Code tab, start a new session, choose Local, and select the SEO folder.
4

The CLIMB prompt

The heart of this guide

Paste this whole prompt. Fill in the yellow parts the first time.

COPY THIS PROMPTCLIMB
You are my SEO agency. My website is https://YOURSITE.com
It's about WHAT YOUR SITE IS ABOUT, for WHO YOUR CUSTOMERS ARE.
My Google Search Console export is in the data folder.

PART 1 - HEALTH CHECK
Visit my main pages and list anything broken or weak: missing or
duplicate titles, missing meta descriptions, broken links, very thin
pages, missing headings, slow or very heavy pages. Rank by importance.

PART 2 - FIND PAGE 2
From the Search Console data, find pages with an average position
between 11 and 20 that get impressions. List the top 5 by impressions,
with the search queries they appear for.

PART 3 - CLIMB
For each of those 5 pages:
1. Read the page as it is now.
2. Search the query and look at what the top 3 results cover that
   my page doesn't.
3. Write an improved version: a better title (under 60 characters),
   a meta description (under 155 characters), the answer in the first
   paragraph, any missing sections, a short FAQ, and 2-3 links to my
   other pages.
Keep my voice. Don't invent facts, stats or reviews. Mark anything
I need to check with [CHECK].

PART 4 - REPORT
Save each rewrite as a separate file in a folder called climb/.
Then give me a short report: what's broken, which pages you rewrote and why,
and what I should publish first.

Do NOT change anything on my live website. Everything is a draft for me to review.
Why "don't change the live site"?

You stay in control. Claude prepares the work, and you decide what goes live. That's how you avoid mistakes reaching your customers and Google.

5

Review and publish

15–30 minutes

Open the files in the climb folder and go through each one with this checklist:

  • Every fact, price and number is correct (search for any [CHECK] marks)
  • It sounds like me, not like a robot
  • It answers the search question clearly in the first paragraph
  • No keyword is repeated unnaturally
  • The links go to the right pages

Then copy the new title, description and content into your website editor and publish. Start with the 1–2 pages Claude says are most important.

6

Make it a daily routine

5 minutes a day
  • Every day: run the health check (Part 1) so you catch broken things fast. If your Claude app has scheduled tasks, schedule it for each morning. Otherwise open the session and say "Run part 1 of CLIMB."
  • Once or twice a week: export fresh Search Console data and run the full CLIMB prompt.
  • Give pages time. After you update a page, wait 2–4 weeks before changing it again. Google needs time to notice.
COPY THIS PROMPTFollow-up run
Run CLIMB again with the new Search Console data in the data folder.
Skip any page I updated in the last 3 weeks (check the climb folders).
Also compare positions with the last run and tell me which pages moved up or down.

Fixes

ProblemWhat to do
Search Console shows no dataNew properties need a few days, and new sites may need weeks of traffic. Keep going with the health check meanwhile.
No pages in positions 11–20Ask Claude to look at positions 8–30 instead, or pick the pages with the most impressions.
Claude can't open my pagesSome sites block automated visits. Copy the page text into a file in the folder and tell Claude to use that.
The rewrite doesn't sound like mePut 2–3 of your best pages in the folder and add: "Match the writing style of these pages."
A page dropped after I changed itSmall drops are normal for a week or two. If it's still down after 4 weeks, go back to the old version.
