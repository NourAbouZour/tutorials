How the AI editor works

Claude Code is a version of Claude that can work with the files and programs on your computer. It doesn't edit video on its own. Instead it uses four free tools, the same way a human editor uses their software:

FFmpeg: the scissors

Cuts, joins, resizes and exports your video. It also adds the music under your voice.

Whisper: the ears

Writes down every word you say, with the exact timing. That's how Claude finds your pauses and syncs your captions.

yt-dlp: the downloader

Downloads a reel from a link, so Claude can study the styles you like.

Hyperframes: the designer

Makes the motion graphics: animated captions, titles, numbers and pop-ups.

1

Install Claude Code and build your folders

About 10 minutes

1a. Download Claude Code

  1. Go to claude.ai/download and download the Claude desktop app for Windows or Mac.
  2. Install it, open it, and sign in with your Claude account.
  3. Click the Code tab at the top. That's Claude Code.

1b. Make your studio folder on the Desktop

On your Desktop, create a new folder called AI Video Editor. Inside it, create these three folders:

FolderWhat goes in it
Raw FootageThe videos you film and want edited. Nothing is ever deleted from here.
ReferencesThe reels whose style you love. Claude studies these to learn how you want your videos to look.
ExportsYour finished, ready-to-post reels. This is where Claude saves every edit.
How to make a folder

Windows: right-click on the Desktop → New → Folder, then type the name. Mac: right-click on the Desktop → New Folder. Spell the names exactly as above, so the prompts in this guide match.

1c. Open the folder in Claude Code

  1. In the Code tab, start a new chat (new session).
  2. When it asks where to work, choose Local. That means your own computer.
  3. Select the AI Video Editor folder on your Desktop.
Always start here

Every time you edit, start your session in the AI Video Editor folder. That's where Claude finds your footage, your style sheet and your finished videos.

2

Install the four editing tools

15–30 minutes, mostly waiting

You don't install anything by hand. Claude does it. The short version from my reel is just: "Install Hyperframes, FFmpeg, Whisper and yt-dlp." This fuller prompt makes it smoother for beginners:

COPY THIS PROMPTInstall the tools
Install Hyperframes, FFmpeg, Whisper and yt-dlp.

I'm a complete beginner on Windows / Mac.
- First check which ones are already installed
- Install anything they need to work (for example Python or Node.js)
- Before each step, explain in one simple sentence what you're doing
- At the end, test each tool and show me a table: tool / installed? / version
If you need me to click or approve something, tell me exactly what to do.

Claude will ask for permission before running commands. Read the one-line explanation, then click Allow. You need to give it all the permissions it asks for here, or the tools can't install. Some downloads are big, so this part can take a while.

"Not found" right after installing?

Sometimes a new tool isn't found until you start a fresh session. Close the chat, open a new one in the same folder, and say: "Test the four tools again."

3

Teach it your style

About 15 minutes · you do this once

A style sheet is a written description of how your reels should look and feel: fonts, colours, captions, transitions and how fast the cuts are. Claude writes it by studying 3–5 reels you love. After this, every edit follows it automatically.

3a. Put your reference reels in References

  • If you have the video files, drag 3–5 of them into the References folder.
  • If you only have links, ask Claude: "Use yt-dlp to download these reels into the References folder: LINK 1, LINK 2, LINK 3"
References are for studying only

Downloaded reels are only there for Claude to learn from. Never repost or reuse other creators' videos. If a download fails (Instagram sometimes blocks it), save the reel another way and put the file in References yourself.

3b. Ask for your style sheet

The short version is: "Analyze these reels and write me a style sheet." This fuller version gets a much more useful result:

COPY THIS PROMPTWrite my style sheet
Analyze the reels in the References folder and write me a style sheet.

For each reel, grab frames with FFmpeg and look at them, and use Whisper
to get the transcript with timings. Then study and measure:
- Fonts: style, weight and size of the captions and titles
- Colours: caption colours, highlight colours, background tones
- Captions: position, words per line, highlighted words, how they animate
- Cutting: average seconds between cuts, how pauses and breaths are removed
- The hook: what happens in the first 3 seconds
- Transitions, zooms and punch-ins: what kind and how often
- Motion graphics: when text, numbers or icons pop up
- Music and sound effects: energy, and how loud compared to the voice
- How the video ends

Save it as style-sheet.md in this folder, written like a guide a professional
editor could follow, with exact numbers wherever possible.
Then show me a short summary of my style.

3c. Read it, adjust it, approve it

  1. Open style-sheet.md (or just read Claude's summary).
  2. Change anything you don't like, in plain words: "Make the captions yellow instead of white", "Use fewer zooms".
  3. When you're happy, reply: approved.

Style sheet template

This is roughly what a good style sheet covers. If Claude's version is missing a part, ask it to add it.

STYLE SHEET TEMPLATEstyle-sheet.md
FORMAT       9:16 vertical, 1080x1920, 30fps
HOOK         Strongest line first, on-screen text in the first 1 second
PACING       Cut every ~2-3 seconds, no pause longer than 0.3 seconds
CAPTIONS     Bold sans font, white with yellow highlight word,
             2-4 words per line, lower third, pop-in animation
ZOOMS        Punch-in 110% on key words, about every 6-8 seconds
GRAPHICS     Numbers, lists and key terms animated in with Hyperframes
MUSIC        Upbeat / calm, about 15% volume, lower when I talk
ENDING       Clear call to action: "Comment WORD"
4

Edit your first reel

About 10–20 minutes, depending on your computer
  1. Film your video normally (see the filming checklist below).
  2. Put it in the Raw Footage folder. Give it a simple name like reel-01.mp4.
  3. Send the prompt. The short version from my reel is: "Edit my video using the style sheet, cut the pauses, add captions, music and motion graphics." The fuller version below gives you more control.
COPY THIS PROMPTEdit my reel
Edit Raw Footage/reel-01.mp4 using my approved style sheet.

1. Transcribe it with Whisper, with word timings.
2. Cut the pauses, the "umm"s, false starts and repeated takes (keep the best take).
3. Make the first 3 seconds a strong hook.
4. Add captions in my style, synced word by word.
5. Add music from the music folder / that fits my style, quieter whenever I speak.
6. Add motion graphics with Hyperframes on key points, numbers and lists.
7. Export as a vertical 1080x1920 MP4 at 30fps to Exports/reel-01-v1.mp4.

Before you render, show me your plan (what you'll cut, and where the
captions, zooms and graphics go) and wait for my OK.

Check the plan, reply OK (or change something), then wait. When it's finished, open the Exports folder and watch your reel.

Music you're allowed to use

Only use music you have the rights to: royalty-free tracks, or music you've licensed. If you're not sure, ask Claude to export without music and add a sound from Instagram's own library when you post.

5

Give feedback like a director

As many rounds as you want

Something you don't like? Captions too big? Music too loud? Just say it in the chat. Claude fixes it itself, like a real editor, and exports a new version.

Keep every version

Ask for each change as a new file: "Save this as v2 and keep v1." If a change makes things worse, you can always go back.

Revision prompts cheat sheet

If…Say this
Captions are too big"Make the captions 20% smaller and move them a little higher."
Music is too loud"Lower the music by half. My voice must always be clear."
A part should go"Cut from 0:12 to 0:15, I stumble there."
The start feels slow"The first 5 seconds are slow. Start with my strongest line and cut faster."

The colours feel off"Make the captions match my brand colours: #6a4cf5 and white."
You love a change"Add this to my style sheet so you always do it."

Filming checklist

The AI editor can cut and caption, but it can't fix dark or noisy footage. These few things make the biggest difference:

  • Light: face a window or a soft light. No strong light behind you.
  • Sound: use a small clip-on mic, or film in a quiet room with soft furniture.
  • Framing: film vertically (9:16), with your eyes about a third from the top.
  • Settings: 1080x1920 (1080p) at 30fps is plenty for reels.
  • Clean stop: pause for a second between sentences. It makes cutting much cleaner.
  • Retakes are fine: just repeat the sentence. Claude keeps the best take.
