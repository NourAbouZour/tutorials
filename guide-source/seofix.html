SEO vs GEO, explained simply

SEO: for Google results

Search Engine Optimisation. It helps your pages show up higher in Google's normal list of links.

GEO: for AI answers

Generative Engine Optimisation. It helps AI tools like ChatGPT and Google's AI answers understand your site, trust it, and mention it.

They overlap a lot. Clear, trustworthy, well-built pages win at both. The skill gives you a separate score for each, so you know where to focus.

1

Install the Claude SEO skill

About 5 minutes
  1. Open the Claude desktop app and click the Code tab.
  2. Start a new Local session and pick a new folder called SEO Fix.
  3. Paste this prompt and click Allow when Claude asks for permission:
COPY THIS PROMPTInstall
Install the Claude SEO skill from https://github.com/AgriciDaniel/claude-seo

Read the README first and follow its install instructions exactly. I'm a beginner on Windows / Mac, so explain each step in one simple sentence.
When you're done, list the /seo commands I can use and what each one does.
Commands can change

The skill is updated often, so command names may change between versions. If a command in this guide doesn't work, type /seo to see the current list, or ask Claude "Which command does the SEO audit now?"

2

Run the SEO audit

5–15 minutes, depending on your site's size

Start a new chat so the skill loads, then type:

TYPE THISFull audit
/seo audit https://YOURWEBSITE.com

The skill sends several specialist "agents" to check your site at the same time. You'll get an SEO Health Score out of 100 and a report. Here's what the main areas mean:

AreaWhat it checks, in plain English
TechnicalCan Google find and read every page? Broken links, a missing sitemap, pages blocked by mistake.
Content quality (E-E-A-T)Does your content show experience and expertise, and can it be trusted? Thin or copied pages score low.
On-pagePage titles, meta descriptions and headings: the basics Google reads first.
SchemaHidden labels that tell Google what things are: your business, products, reviews, FAQs.
Speed and mobileHow fast pages load, and how they work on a phone.
3

Run the AI-search (GEO) check

5 minutes
TYPE THISAI search check
/seo geo https://YOURWEBSITE.com

This gives you a score for how ready your site is for AI search. It checks things like:

  • Clear answers: does each page answer real questions directly, in the first lines?
  • Structured data: can AI easily understand who you are, what you sell and where you are?
  • llms.txt: a simple file that tells AI tools what your site is about and which pages matter.
  • Trust signals: author details, reviews, contact info, and mentions of you on other sites.
4

Merge both into one fix list

2 minutes · this is the magic step

Two long reports are overwhelming. Ask Claude to combine them:

COPY THIS PROMPTOne fix list
Combine the SEO audit and the GEO report into ONE prioritised fix list.
For each fix, show:
- What's wrong (in simple words) and which page(s)
- Why it matters for Google, for AI search, or both
- How hard it is: quick (under 10 min) / medium / big
- Expected impact: high / medium / low
Sort by impact first, then by how quick it is. Put the quick, high-impact wins at the top.
Save it as fix-list.md in this folder.
5

Apply the fixes safely

Claude writes them, you check them
Back up first, review always

Before you change anything, make a backup of your website (most hosts and website builders have a backup button). Review every change before it goes live. Never let any tool publish to your live site without you checking it first.

If you built your site yourself (code in a folder)

COPY THIS PROMPTFix the code
My website's code is in this folder: FOLDER NAME
Work through fix-list.md from the top. Make the changes in the code, one fix at a time. After each one, show me what you changed and wait for my OK before the next.
Don't publish anything. I'll check the changes and upload them myself.

If you use WordPress, Shopify, Wix or Webflow

Claude can't click inside your website builder for you, but it can prepare everything so you just copy and paste:

COPY THIS PROMPTCopy-paste fixes
My site is built with WordPress / Shopify / Wix / Webflow.
For each fix in fix-list.md, give me:
1. Exactly where to click in my builder to find the setting
2. The exact text or code to paste (new titles, descriptions, FAQ, schema, llms.txt)
Start with the top 5 quick wins.
6

Re-check every month

10 minutes a month
  • Run /seo audit and /seo geo again once a month.
  • Ask Claude: "Compare these scores with last month's and tell me what improved, what got worse, and what to fix next."
  • Keep each month's reports in the folder so you can see your progress over time.
Be patient and realistic

A higher score means your site is healthier. It doesn't guarantee a top spot on Google or a mention in ChatGPT. Google can take weeks to notice changes, and results depend on your competition too. Keep improving month after month.
