Before you start

  • Claude desktop app with the Code tab (Claude Code), from claude.ai/download. It comes with paid Claude plans.
  • Your website in Google Search Console. If it isn't there yet, go to search.google.com/search-console, add your site and verify it. Claude can walk you through it.
  • A folder called SEO on your computer. Open the Claude desktop app, click Code, start a Local session and choose that folder. You'll do everything in this guide from there.
Let Claude do the technical part

Each tool has a GitHub page with its install steps. You don't need to understand them: give Claude the link and ask it to install it and explain each step. Never paste passwords or API keys into the chat. Claude will tell you which file or screen to put them in.

Plugin 1: Google Search Console MCP

1

Install it

20 minutes · the longest setup

An MCP is a connector that lets Claude use another tool. This one (mcp-gsc, by Amin Foroutan) gives Claude read access to your Search Console. Paste this into Claude Code:

COPY THIS PROMPTInstall GSC MCP
Install the Google Search Console MCP from
https://github.com/AminForou/mcp-gsc for Claude Code on this computer.

I'm a beginner. Read the README, then guide me step by step through:
1. Installing what it needs (it uses "uv").
2. Creating a Google Cloud project, turning on the Search Console API,
   and creating an OAuth client ID (Desktop app). Tell me exactly
   which buttons to click. I'll do the Google screens myself.
3. Where to save the credentials file, and adding the MCP to Claude Code.
4. Testing it by listing my Search Console properties.
Keep it read-only.

The first time you use it, a browser window opens to sign in to Google. Use the account that has access to your Search Console, and click Allow.

Plugin 2: OpenSEO

3

Choose how to run it

5 minutes

OpenSEO (by Every App) is an open-source alternative to Semrush and Ahrefs. The software is free. The SEO data (search volumes, rankings, backlinks) comes from a data provider called DataForSEO, which charges per use, usually much less than a monthly Semrush plan. You have two options:

OptionGood for
Hosted at openseo.soThe easiest. You can try it for free, then there's a low monthly plan. Data use is included at a small markup. No technical setup.
Self-hostedThe cheapest if you use it a lot. You run it in your own account and pay DataForSEO directly. Claude Code can set it up for you.

Check current prices on openseo.so and dataforseo.com before you start.

4

Connect it to Claude Code

10–20 minutes
COPY THIS PROMPTInstall OpenSEO
I want to use OpenSEO (https://github.com/every-app/open-seo) with
Claude Code. I chose the hosted / self-hosted option.

Read the README and its MCP and skills docs, then guide me step by step:
1. What account(s) I need to create, and what each one costs.
2. Setting it up, and where I paste my DataForSEO key (in a settings
   file or their website, never in this chat).
3. Connecting its MCP server and skills to Claude Code.
4. A test: research 10 keywords for my site YOURWEBSITE.COM.
Set a spending limit

In your DataForSEO account, add a small amount of credit first (for example $5–10) and watch how fast you use it. Every search Claude runs uses a little.

Plugin 3: GEO Optimizer Skill

GEO means generative engine optimization: making your site easy for AI assistants to find, understand and recommend. When someone asks ChatGPT, Claude or Google's AI Overviews about your topic, you want your site in the answer instead of your competitors'.

6

Install it

5 minutes

This is geo-optimizer-skill by Auriti Labs. It installs as a Claude Code plugin. In Claude Code, type these two commands one at a time:

TYPE IN CLAUDE CODEInstall the plugin
/plugin marketplace add Auriti-Labs/geo-optimizer-skill
/plugin install geo-optimizer@geoready

It needs uv and Python 3.10 or newer. If you installed the GSC MCP in Step 1, you already have uv. If something's missing, just say: "Install whatever the GEO Optimizer plugin needs, and check it works."

7

Audit and fix your site for AI search

10 minutes
COPY THIS PROMPTGEO audit
Run a GEO audit on YOURWEBSITE.COM. Give me the score out of 100, what's
holding it back, and the fixes in order of impact. Explain each one simply.

It checks things like whether AI crawlers are allowed in your robots.txt, whether you have an llms.txt file, your structured data (schema) and meta tags, and how easy your content is to quote. Then:

COPY THIS PROMPTMake the fixes
Prepare the fixes (robots.txt rules, llms.txt, schema and meta tags).
Show me a preview first. After I approve, save the files and tell me
exactly where to upload them on my website.
No tool can guarantee AI citations

GEO Optimizer makes your site technically ready for AI search. It improves your chances, but the AI decides what to cite. Great, clear, useful content still matters most.

8

Your weekly SEO routine

15 minutes a week

Once all three are installed, one prompt uses them together:

COPY THIS PROMPTEvery Monday
Weekly SEO check for YOURWEBSITE.COM:
1. Search Console: what changed this week, wins and drops.
2. My 5 easiest keyword wins right now, and what to fix on each page.
3. OpenSEO: my tracked rankings, and one competitor gap to go after.
4. GEO: anything that hurts my AI visibility.
Finish with my top 3 tasks for this week.

Fixes

ProblemWhat to do
"No properties found" in Search ConsoleYou signed in with the wrong Google account. Ask Claude to re-authenticate and pick the account that owns the site.
"uv" or "uvx" not foundAsk Claude: "Install uv on this computer and add it to my PATH." Then restart the Claude app.
The MCP doesn't show up in Claude CodeRestart the Claude app, then ask Claude to list its connected MCP servers.
OpenSEO returns no dataCheck your DataForSEO key and credit balance.
The /plugin command isn't recognizedUpdate the Claude desktop app to the latest version and try again.
I uploaded the GEO files but the score didn't changeCheck they're live (open yoursite.com/llms.txt in a browser), then run the audit again.

Your checklist

  • My site is verified in Google Search Console
  • The GSC MCP is installed and lists my properties
  • I found keywords where I'm on positions 8–20
  • OpenSEO is connected and I set a DataForSEO spending limit
  • I did keyword research and a competitor check by chatting
  • The GEO Optimizer plugin is installed
  • I ran a GEO audit and uploaded the fixes
  • I saved my weekly SEO prompt

Mini glossary

Google Search ConsoleGoogle's free tool that shows how your site performs in Google Search.
MCPModel Context Protocol: a standard way to connect Claude to other tools and data.

DataForSEOA paid-per-use provider of SEO data that OpenSEO uses.
GEOGenerative engine optimization: getting your site cited by AI assistants.
llms.txtA file that gives AI assistants a clear summary of your site.
SchemaHidden labels on your pages that tell search engines what things are.
