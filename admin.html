Set up your admin

You only do this once. Paste a GitHub token and choose a password. The token gets locked with your password, so from then on you only need the password, on any device.

How to get your token (2 minutes)
  1. Open GitHub → Fine-grained token (signed in as NourAbouZour).
  2. Name: Guides admin. Expiration: for example 1 year.
  3. Repository access: Only select repositories → tutorials.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it, and paste it below. Never send it to anyone or paste it in a chat.

Use a long password you don't use anywhere else. If you forget it, just set things up again with a new token.
