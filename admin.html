To switch guides on and off, connect this page to your GitHub once. On each device you use, you'll need a GitHub token: a key that lets this page update only your tutorials repo.

How to get your token (2 minutes)
  1. Open GitHub → Fine-grained token (signed in as NourAbouZour).
  2. Name: Guides admin. Expiration: choose how long you want (for example 1 year).
  3. Repository access: Only select repositories → tutorials.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it, and paste it below.

The token is saved only in this browser on this device. It never goes on the website. Anyone who uses this device and browser can make changes, so only connect devices you trust.
